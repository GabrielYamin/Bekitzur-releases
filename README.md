# Bekitzur has moved

Bekitzur is open source now. Its code, releases, and updates are at [github.com/GabrielYamin/Bekitzur](https://github.com/GabrielYamin/Bekitzur), along with how to install it.

If you already have Bekitzur, you don't need to do anything: its next update comes from here as before, and from then on it checks for updates there. Your Conversations, names, and settings stay.

Versions before 0.2.0 can't update themselves. Update those once by hand from the [latest Bekitzur.zip](https://github.com/GabrielYamin/Bekitzur/releases/latest/download/Bekitzur.zip): open it and run `bash ~/Downloads/Bekitzur/install.sh` in Terminal, which replaces the app and keeps your data and models.
